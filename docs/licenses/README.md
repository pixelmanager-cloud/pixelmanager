# Third-party asset licenses

Proof-of-rights for third-party assets bundled in the game. Keep the EULA + purchase receipt for every
paid asset here, and make sure any attribution obligation is reflected in `/CREDITS.md` (and the in-game
credits screen).

## Bit By Bit Sound — game music (+ SFX if the bundle was bought)
- **Creator / licensor:** Robert "Bert" Cole — Bit By Bit Sound (https://www.bitbybitsound.com)
- **Pack(s):** Ultimate Retro RPG Music Pack (400+ tracks). *(If the $97 bundle was purchased, the Ultimate
  Sound Effects Pack is covered by the same EULA — one shared credit line suffices, same creator.)*
- **Binding license:** `bitbybitsound-EULA-2022-08.pdf` (in this folder). Purchased 2026-08-27.
- **Grant (what we CAN do):** non-exclusive, worldwide **Synchronisation + Master Use** license — use the
  music as background/in-sync audio in a **commercial game**, **in perpetuity**, across **multiple projects**,
  no further fees; **editing/trimming and derivative works allowed** (e.g. custom loop points).
- **MUST do / MUST NOT (compliance):**
  - ✅ **Attribute** — credit line in the game credits (see `/CREDITS.md`). Do NOT imply the licensor endorses
    or supports the game.
  - ❌ **Never register with Content ID or a royalty-collection agency** (YouTube Content ID, PRS/ASCAP/BMI).
    Don't claim the music on trailers/streams.
  - ❌ **No standalone soundtrack product** — cannot sell a "Football Royalty OST" (Steam Soundtrack DLC,
    Spotify/Apple album) using these tracks without a **separate publishing agreement** from the licensor.
    The game itself with embedded music is fully covered.
  - ❌ **Don't redistribute the tracks as a standalone audio product** — embed in the game only; don't offer
    the raw files as a downloadable music pack. (A web build's `/audio/` OGGs being fetchable is normal
    game-asset serving, not a "standalone audio product"; the Steam desktop build bundles them internally.)
